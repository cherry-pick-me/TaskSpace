# Проверки M3: переходы, версии и транзакции

Дата: 2026-10-05. Windows 10 Pro, .NET SDK 10.0.401, файловая SQLite в режиме WAL (новая база на каждый тест).

```bash
dotnet test --filter "FullyQualifiedName~WorkflowTransitionTests"   # только M3: 18/18
dotnet test                                                           # весь набор: 104/104
```

Весь набор прогнан шесть раз подряд: 104/104 в каждом прогоне. Код: [TaskWorkflow](../src/TaskSpace.Api/Services/TaskWorkflow.cs), [WorkflowService](../src/TaskSpace.Api/Services/WorkflowService.cs), [WorkflowEndpoints](../src/TaskSpace.Api/Endpoints/WorkflowEndpoints.cs). Тесты: [WorkflowTransitionTests](../tests/TaskSpace.Api.Tests/WorkflowTransitionTests.cs). «Без изменений» означает совпадение снимка всей базы до и после запроса: задачи, сдачи, решения, сессии.

Учебные данные: задача 1 (команда A, автор alice, исполнитель bob, «Назначена», версия 1); задача 3 (команда B, автор dave, исполнитель erin, «На проверке», версия 4, текущая сдача 2, сдача 1 возвращена); frank состоит в A и B, но не автор и не исполнитель.

## Работающий сервер

```bash
dotnet run --project src/TaskSpace.Api            # в первом терминале
bash scripts/m3-counterexample.sh                  # во втором; BASE=http://… для другого адреса
```

Скрипт создаёт новую задачу и проходит контрпример через HTTP. Фактический вывод на временной базе:

```text
2. Автор возвращает R1 (версия 2 → 3): 201
3. Исполнитель сдал R2=6 (версия 3 → 4)
4. Старая вкладка: принять R1 с версией 2 → 409 {"error":"Задача изменилась. Перечитайте её и повторите действие."}
Текущее состояние:
  "status":"InReview","version":4,"currentSubmissionId":6
5. Новое решение по R2 с версией 4 → 201
```

## Границы

- Свидетельства относятся к локальному серверу и SQLite. Неизменяемость истории обеспечивается API, а не защитой файла базы от администратора.
- Сервер не повторяет команду после `409`; повтор выполняет пользователь после перечитывания (клиент M2 проверен DOM-тестом).
- Человеческая проверка этих результатов участником M3 должна быть отмечена в [AI_USAGE.md](../AI_USAGE.md#сценарии-и-транзакции-m3).
