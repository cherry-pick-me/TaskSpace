Содержательная проверка документов выполнена всеми участниками: M1 проверил D-01/D-02, M2 — D-03/D-05 и контрпример двух вкладок, M3 — D-04 и обновлённые SR-06/SR-10. Эти результаты являются проверкой проектных решений и трассировки. Проверки механизмов на работающем API, конкурентные запросы, откат реальной SQLite-транзакции и DOM-проверка ещё не выполнялись.


## Реализация M2

- Интеграционные проверки на файловой SQLite: независимые сессии, SR-01/SR-03/SR-07/SR-09, отказ без изменения данных, старое решение и конкурентная сдача (`WorkflowTests`, `AuthenticationTests`).
- Smoke настоящего HTTP-сервера: создание задачи, сдача и принятие, остановка процесса и проверка сохранённой истории после запуска (`ServerSmokeTests`, `scripts/smoke.sh`).
- Негативные проверки и необходимый API сдачи/решения: серверная роль, версия, текущая сдача и откат транзакции. В следующем коммите M2 добавлен React, проверка SR-11 описана ниже.

Команды и протокол: [M2_CHECKS](docs/M2_CHECKS.md). Commit реализации: `c73e8c574280eeb2dd335018431b2cccc6d92a6f` (`M2: add workflow API integration and restart smoke checks`). Фактический результат: 86/86 тестов и 1/1 отдельный smoke, 2026-10-05, .NET SDK 10.0.401.

### React-клиент M2

- `web/`: вход, список команды, задача с историей, сдача, принятие и возврат; bearer только в памяти и обычные JSX-выражения для всех пользовательских текстов.
- DOM-проверки: строка с HTML не создаёт b/img/script и не вызывает запись API; токен отсутствует в storage/cookie и теряется при новом mount; конфликт 409 перечитывает задачу и не повторяет решение; формы сдачи/возврата и 401.
- Проверка: `npm --prefix web test` — 6/6; `npm --prefix web run build` — успешно. Протокол: [M2_WEB_CHECKS](docs/M2_WEB_CHECKS.md). Ручная визуальная проверка ещё не выполнена.
