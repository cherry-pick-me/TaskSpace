# Использование генеративного ИИ

## Выбор темы, объёма и стека

- Участник: M1
- Задача: сузить тему № 17 «Командные задачи» до небольшого продукта и выбрать стек
- Использование ИИ: Codex предложил несколько вариантов названия, набора функций и стека
- В проект вошло: название TaskSpace, три сценария (назначение задачи, сдача и приёмка, возврат на доработку), серверный стек C#, ASP.NET Core, EF Core, SQLite
- Проверка человеком: название, объём и стек выбраны M1 из предложенных вариантов; стек соответствует основному стеку курса
- Связанный результат: разделы 1, 4 и 9 [PROJECT.md](PROJECT.md)

## Доработка паспорта

- Участники: M1, M2, M3
- Задача: довести черновик паспорта до требований S01
- Использование ИИ: черновик разделов 1–9 сделан M1 с помощью Codex; разбор черновика и правки по принятым командой замечаниям — с помощью Claude Code (M3)
- В проект вошло: исправленный паспорт. Основные изменения:
  - веб-интерфейс убран из обязательного ядра, сценарии можно пройти запросами к API;
  - в списке того, что можно исключить, вместо фильтров и поиска теперь веб-интерфейс, полная история сдач и членство в нескольких командах;
  - в таблицу данных и в источники данных добавлены учётные записи и сессии;
  - уточнены полномочия: нельзя назначить исполнителем себя, задачу нельзя менять после создания, пользователь может состоять в нескольких командах.
- Проверка человеком:
  - замечания обсудили втроём и приняли;
  - вместо простой тестовой страницы решили делать полноценный веб-интерфейс на React, им займётся M2; в обязательное ядро он не входит;
  - отдельно согласовали решения, которых не было в черновике: несколько команд у пользователя, запрет менять задачу после создания, вход через сессию;
  - какие технологии для нас новые (ASP.NET Core, EF Core и React), указали сами;
  - M2: вычитка итогового текста и проверка, что переходы состояний в сценариях не противоречат таблице полномочий.
- Связанный результат: [PROJECT.md](PROJECT.md)
